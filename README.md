# eco-cv-exp

Результаты экспериментов по компьютерному зрению для экологических задач.

- [sludge — микроорганизмы активного ила](sludge/README.md): отчёты, метрики,
  предсказания, протоколы и снимок кода по состоянию на 23.10.2026.
- [lion — личинки чёрной львинки](lion/README.md): эксперименты, фолды,
  метрики, код и иллюстрированный аудит разметки; без весов моделей.

Это исследовательский архив, не готовый к развёртыванию продукт.
