Снимок результатов по состоянию на **23 октября 2026 года**. Задача — сегментация
фона, светлых активных личинок (`active`) и потемневших зрелых особей (`mature`).
Каталог содержит код, конфигурации, результаты всех сохранённых серий, логи,
прогнозы и иллюстрированные отчёты. Веса моделей исключены по просьбе пользователя.

## Как интерпретировать оценки

Это исследовательский архив. Прежнее разбиение по ID изображений и позднее
сценовое разбиение — разные протоколы; их метрики нельзя объединять или называть
независимым тестом. При сравнении моделей проверяйте совпадение `train_ids`,
`validation_ids`, оценку полных кадров с Flip4 и stride 448.

Последующий визуальный аудит обнаружил совпадающие участки сцен A/G, попавшие
в разные фолды. Поэтому даже сценовый CV нельзя считать полностью независимой
проверкой обобщения. Сохранённые файлы разбиения отражают фактически использованный
протокол и не исправлены задним числом.

Аудит разметки — обзор всех 69 кадров с увеличением отдельных мест, а не
подтверждение правильности каждого пикселя. Несовпадение прогноза и разметки
само по себе не доказывает ошибку разметчика. DINOv3 без официальных gated-весов
не запускался; результаты другой модели не выданы за DINOv3.

## Состав и воспроизведение

[MANIFEST.json](MANIFEST.json) перечисляет все файлы исходного каталога:
для включённых указаны путь в репозитории, размер и SHA-256; для исключённых —
размер и причина исключения. Перенесены **594 исходных файла, 95 145 143 байта**.

Не входят в снимок:

- 1266 файлов весов из `larvae_cv_task` (156 772 881 472 байта);
- скачанный внешний датасет, исходные `task/coco_export`, архивы и кэш предобученных весов;
- локальные блокировки и Python-кэш.

Иллюстрации отчётов, маски прогнозов и `external/copy_paste_preview.png` включены.
Исходные датасеты являются входами исследования и хранятся отдельно; данный
репозиторий содержит результаты, но не является самостоятельной поставкой данных.

Код и конфигурации находятся в [larvae_cv_task](larvae_cv_task).
Для повторения обучения прочитайте [исходный README](larvae_cv_task/README.md),
установите зависимости из `requirements.txt` и предоставьте исходный COCO-датасет.
Относительные пути конфигураций ожидают каталог `lion/task/coco_export` рядом
с `lion/larvae_cv_task`; некоторые вспомогательные скрипты содержат абсолютные
пути исходной Windows-машины и требуют настройки. Путь `torch_home` указывает
на отдельный локальный кэш. Архивные результаты и инструкции сохранены как снимок;
для новых запусков задавайте новый `output_dir`.
