# Третья ночь: каскад и специализированные детекторы

Итог подготовлен 22.10.2026 после досрочного завершения зарегистрированного бюджета, до deadline 23.10.2026 08:00 МСК.

## Решение

Все **12 pipeline jobs / 24 обучения компонентов** завершились успешно. Ни каскад, ни специалисты не прошли заранее зафиксированные критерии eligibility. Рабочие веса не заменены, автоматического деплоя нет. Дополнительные эксперименты не запускались.

Специалисты повысили средний macro F1 с 0.3116 до 0.3404, но ухудшили ошибки подсчёта прикреплённых инфузорий и нитчатых бактерий. Каскад оказался хуже контроля по macro F1 и обеим приоритетным count MAE. Это результат конкретных зарегистрированных рецептов, а не доказательство бесперспективности самих архитектур.

- Прочитаны все 24 `resume_state.pt`: последние полные эпохи сохранены, доступны optimizer/RNG/history. Проверены хеши регистрации, входов, моделей и калибровок; loss конечны, frozen BN неизменны, crop IDs относятся к FIT. Калибровки записаны до outer inference.

## PRIMARY: count_guarded

Порог macro F1: ≥0.301569. Attached MAE: ≤0.738971. Filamentous MAE: ≤0.970588. Ни один class F1 не должен упасть больше чем на 0.02 относительно контроля. Все условия обязательны одновременно.

У специалистов macro F1 вырос на 2.89 процентного пункта, но attached MAE выросла на 4.8%, filamentous MAE — на 7.7%. Attached F1 снизился с 0.340167 до 0.315260, на 0.024907, что отдельно нарушает ограничение по классу.

Средний signed count bias для attached / filamentous: контроль −0.2917 / −0.4706; каскад −0.1324 / −0.3897; специалисты −0.3554 / −0.2892 объекта на кадр. Отрицательный знак — недосчёт. Уменьшение модуля среднего bias не гарантирует меньшую MAE: ошибки противоположного знака могут взаимно компенсироваться.

## Локализация и отдельная классификация

Диагностика при фиксированном raw score 0.05 и IoU 0.5, до выбора calibration-порогов. Confidence разных архитектур несопоставимы напрямую: это не сравнение при одинаковом precision или recall.

У контроля localization recall = 0.7709 для обоих seed. У class-agnostic предложений **до классификатора** recall = 0.8034 / 0.7610, precision = 0.1390 / 0.1359. После каскада localization recall падает до 0.4866 / 0.5050. Следовательно, существенная часть потерь возникает после получения предложений; здесь одновременно действуют классификатор, произведение scores и NMS, поэтому нельзя приписывать всё одной причине.

Классификация идеальных outer GT-crops даёт accuracy **0.4866 ± 0.0200**; доля настоящих объектов, названных фоном, — **0.4257 ± 0.0160**. Полные матрицы ошибок 8×8 для обоих seed находятся в приложении и [final_diagnostics.json](experiments_updated_2026_10_02/overnight_2026_10_23/final_diagnostics.json). Это oracle-диагностика, не достижимая на реальном входе метрика и не основание для выбора порогов.

Matched-class accuracy конечного каскада = 0.8517 / 0.8655, но только среди сохранившихся matched boxes; это не общая точность классификатора. Duplicate FP = 44 / 37.

У специалистов localization recall = 0.7440 / 0.7341, precision = 0.1095 / 0.1187, matched-class accuracy = 0.8099 / 0.8035, duplicate FP = 386 / 359. У диагностического union duplicate FP = 447 / 400. Полные локализационные результаты всех методов по seed, включая контроль, находятся в приложении. Эти низкопороговые дубликаты нельзя напрямую отождествлять с PRIMARY count error.

## Ограничения и следующие шаги

1. Внешние folds уже смотрели в предыдущих исследованиях: это **adaptive development, не независимый test**. Перестановка известных кадров не создаёт новый независимый test. Train IDs релизной модели неизвестны, поэтому превосходство над релизом не заявляется.
2. Неполная разметка может создавать ложные background crops. Proposal mining проведён in-sample на FIT, не out-of-fold. Это возможные ограничения, но причина наблюдаемого отбрасывания объектов классификатором ещё не доказана.
3. Поддержка редких классов мала: free_swimming_ciliates 28, nematoda 23, gastrotrichs 27 объектов во всём outer OOF. Два seed недостаточны для надёжной оценки неопределённости; SD — не доверительный интервал и не доказательство значимости.
4. Confidence разных специалистов не гарантированно сопоставимы, настоящие объекты могут перекрываться. Union остаётся диагностикой; правило merge по итогам не менялось.
5. Новые pipelines используют больше параметров и вычислений. Качество измерено относительно имеющейся разметки, не абсолютной биологической истины.

Рекомендуемые действия **после нового согласования**, не выполненные этой ночью: экспертная проверка пропусков и background crops с Student_6 как основной разметкой; уточнение единицы подсчёта колоний и нитей; отдельная валидация crop-классификатора на FIT/calibration по новому заранее записанному протоколу; сбор действительно новых независимых кадров для финальной проверки. Текущую модель оставить без изменений.
